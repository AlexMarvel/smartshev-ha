# SmartShev для Home Assistant

Підключіть шлюз ShevLogger, щоб бачити в Home Assistant потужність інвертора, заряд батареї та споживання будинку. Показники залежать від моделі й профілю інвертора. Їх можна додавати на панелі та використовувати в автоматизаціях Home Assistant.

## Встановлення через HACS

Потрібен Home Assistant 2024.8 або новіший і налаштований шлюз ShevLogger.

1. У HACS відкрийте **⋮ → Користувацькі репозиторії**. Додайте `https://github.com/AlexMarvel/smartshev-ha` з типом **Інтеграція**.
2. Завантажте **SmartShev** через HACS і перезапустіть Home Assistant.
3. Відкрийте **Налаштування → Пристрої та служби → Додати інтеграцію → SmartShev**. Якщо шлюз уже з’явився серед знайдених пристроїв, відкрийте його там.

Для ручного встановлення скопіюйте [папку `shevlogger`](custom_components/shevlogger) у `/config/custom_components/` і перезапустіть Home Assistant.

## Підключення шлюзу

**Локально.** У майстрі SmartShev виберіть **Локально вручну**. Власник шлюзу може скопіювати токен у застосунку SmartShev через **Можливості → Інтеграції → Home Assistant**. Вкажіть локальну адресу шлюзу й вставте токен. Якщо Home Assistant сам знайшов шлюз, достатньо токена. Сенсори й дозволені профілем налаштування працюють через локальну мережу без інтернету.

**Через акаунт.** Виберіть **Увійти в SmartShev**, відкрийте посилання й підтвердьте підключення. Поверніться до Home Assistant та оберіть шлюз. Власнику доступно **Локально (LAN)**. Виберіть **Хмара SmartShev**, щоб переглядати сенсори з іншої мережі. Хмарний режим доступний, якщо власник шлюзу має Full і ввімкнув віддалений доступ.
